# Design System Inspired by N26

## 1. Visual Theme & Atmosphere

N26's design language is an exercise in radical reduction. The German neobank operates on a strict black-and-white foundation — jet black (`#000000`) and pure white (`#FFFFFF`) — with a single teal accent (`#41CEB1`) used sparingly as a signal of life and interaction. The result is a banking UI that feels more like premium consumer electronics than financial software. Every element earns its place; decorative elements are absent by design philosophy.

The custom N26 typeface (a geometric sans-serif family commissioned exclusively for the brand) carries the entire typographic system with exceptional weight variety. Headlines use Heavy (900) weights at generous sizes to create immediate hierarchy. Body copy stays compact but airy, with generous letter-spacing that signals premium quality. Dark mode is a first-class citizen — the color system inverts cleanly, with the teal remaining consistent as the sole accent across both themes.

The atmosphere is aspirational minimalism: the bank account of someone who cares about design. Financial data is presented without decoration — transaction lists are pure type on white space, balances are displayed at large scale without surrounding chrome. The Mastercard co-branding appears as a discrete two-circle logo, never over-designed. Animations are swift, purposeful, 200ms cubic-bezier transitions.

**Key Characteristics:**
- Strict black-and-white system with teal `#41CEB1` as sole chromatic accent
- Custom N26 geometric sans-serif — weights from Light (300) to Heavy (900)
- Dark mode inverts cleanly: `#000000` surfaces, `#FFFFFF` text, teal preserved
- Zero decorative elements — every visual element carries functional meaning
- Card design using physical card metaphor: 16:9 ratio, dark gradient, embossed number treatment
- Transactions: text-only rows — no icons, no categories colors by default
- Micro-animations at 200ms with `cubic-bezier(0.4, 0, 0.2, 1)` easing
- Spacing: 4px base, 8px primary unit — extremely tight, disciplined grid

## 2. Color Palette & Roles

### Primary
- **Jet Black** (`#000000`): Primary surfaces in dark mode, text in light mode, CTA buttons
- **Pure White** (`#FFFFFF`): Primary surfaces in light mode, text in dark mode, card faces
- **Teal Accent** (`#41CEB1`): Single chromatic accent — active states, success, brand highlight

### Neutrals
- **Gray 900** (`#111111`): Dark text, headers in light mode
- **Gray 700** (`#333333`): Secondary text, labels
- **Gray 500** (`#777777`): Tertiary text, inactive tabs, placeholders
- **Gray 200** (`#E0E0E0`): Dividers, borders, input outlines in light mode
- **Gray 100** (`#F5F5F5`): Subtle surface differentiation, hover states

### Dark Mode Surfaces
- **Dark Base** (`#000000`): App background
- **Dark Card** (`#111111`): Elevated cards on dark base
- **Dark Surface** (`#1A1A1A`): Modals, sheets over dark base
- **Dark Border** (`#2A2A2A`): Dividers on dark surfaces

### Status
- **Success Teal** (`#41CEB1`): Positive balance, successful transfers, verified states
- **Error Red** (`#E33939`): Failed transactions, error states
- **Warning Amber** (`#F5A623`): Pending, awaiting confirmation

### Interactive
- **Black Hover** (`#222222`): Primary button hover
- **Teal Muted** (`rgba(65, 206, 177, 0.12)`): Teal accent ghost background

## 5. Layout Principles

### Spacing System
- Base: 4px
- Scale: 4px, 8px, 12px, 16px, 20px, 24px, 32px, 40px, 48px, 64px, 80px
- Page margins: 24px mobile, 40px tablet, 0 (centered container) desktop
- Section spacing: 40px between major sections
- Transaction row padding: 16px vertical, 0 horizontal (edge-to-edge dividers)

### Border Radius Scale
- `2px` — Input borders, micro-elements
- `4px` — Buttons, tags, small containers
- `8px` — Content cards, list containers
- `12px` — Payment cards, modals
- `50%` — Avatar, circular icon buttons

### Grid
- Mobile: 1-column, 24px margins
- Tablet: max-width 480px centered
- Web app: max-width 400px centered column (app-first product, intentionally narrow)

## 6. Depth & Elevation

```
Level 0 - Flat:        no shadow (transaction rows, list items)
Level 1 - Card:        0 2px 8px rgba(0,0,0,0.08)
Level 2 - Modal:       0 8px 32px rgba(0,0,0,0.16)
Level 3 - Payment Card:0 20px 60px rgba(0,0,0,0.40)
Level 4 - Drawer:      0 -4px 24px rgba(0,0,0,0.20)
Dark mode multiply:    all shadows at 60% opacity (dark surfaces absorb less)
```

## 7. Do's and Don'ts

### Do
- Use `#41CEB1` teal sparingly — one accent per screen maximum for visual impact
- Implement true dark mode with `#000000` backgrounds (not dark gray)
- Display account balance at 48px minimum — it's the primary data point
- Keep transaction rows text-only — resist adding category icons or color coding
- Use full-width black buttons on mobile for strong CTA tap targets
- Apply `cubic-bezier(0.4, 0, 0.2, 1)` easing for all transitions — it's the N26 signature

### Don't
- Don't introduce secondary accent colors — the teal is the only chromatic element
- Don't use border-radius above 12px — the precision aesthetic requires sharp edges
- Don't add decorative illustrations or gradients to standard UI surfaces
- Don't use system fonts in brand-critical contexts — the N26 typeface is non-negotiable

## 8. Responsive Behavior

**Breakpoints:**
- `375px` — Primary mobile target (iPhone-first design)
- `390px` — iPhone 14 Pro optimization
- `768px` — Tablet: card becomes floating panel with white border
- `1024px` — Desktop: single centered column max 440px, full-height sidebar optional
- `1440px` — Large screens: split-pane with card visualization left, controls right

**Adaptive Patterns:**
- Balance: 48px mobile → 64px desktop
- Navigation: bottom tab bar mobile → left sidebar desktop
- Transaction list: full-width mobile → max-width 480px desktop
- Payment card: full-width mobile → fixed 340px desktop
