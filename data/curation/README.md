# Curation Outputs

This directory is reserved for structured outputs created by backstage agents.

Recommended contents:

- `coverage/`: audit reports, freshness reports, and gap tracking.
- `flows/`: approved flow packs with step metadata.
- `patterns/`: evidence-backed design system notes and comparisons.
- `brand/`: positioning briefs, messaging approvals, and copy review notes.

The product UI should prefer curated outputs from this directory over improvised runtime content.
